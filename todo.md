**jaudiotagger findings for the adapter (3.0.1)**
- Reading: `AudioFileIO.read(File)` returns an `MP3File`. It exposes `getID3v1Tag()`, `getID3v2Tag()` and `getMP3AudioHeader()`. The header gives `getPreciseTrackLength()` in seconds, `getBitRateAsNumber()` and `isVariableBitRate()`.
- Corrupt and empty files: both throw `InvalidAudioFrameException`, which should map to `CORRUPT`. Check that the file exists and is readable first, so `NOT_FOUND` and `ACCESS_DENIED` come out right.
- Generic text fields: `tag.getAll(FieldKey.X)` works for the plain text fields and for year. v2.4 `TDRC` gives `2020-05-01`, so take the leading four digits.
- Track and disc:
  - `getFields(FieldKey.TRACK)` silently drops an invalid `TRCK` such as "A1". Use frame level instead: `getFrame("TRCK")` or `"TPOS"`, or `"TRK"` and `"TPA"` for v2.2.
  - Read `AbstractFrameBodyNumberTotal.getText()`, strip it, and parse it yourself.
  - Raw text carries a trailing space, for example `"3/12 "`.
- Genre: use frame-level `TCON`, or `TCO` for v2.2.
  - Read `getText()`, which includes trailing NULs, and split on NUL.
  - Run each part through `Id3v1Genres.resolveReference`.
  - jaudiotagger itself splits `(17)Rock` into `[(17), Rock]`, so don't use `getValues()`.
- Comments: take `getFields(FieldKey.COMMENT)`, which are `FrameBodyCOMM`, and use the first with an empty description.
- Cover: `getArtworkList()` gives picture type (3 is front cover), MIME type and size. Fall back to the first picture, typed `OTHER`.
- ID3v1: `ID3v11Tag` means v1.1 and `ID3v1Tag` means v1.0. The tag exposes the genre only as a name, via `getFirstGenre()`. I was still deciding how to map that name onto `Id3v1Genres`.
- JUL loggers: keep a strong reference to the configured `Logger`, because JUL holds loggers weakly.
